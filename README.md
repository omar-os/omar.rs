# omar.tech

Website for the OMAR (One-Man Army) project. Built with [Astro](https://astro.build/).

## Prerequisites

- Node.js >= 22

## Development

```bash
# install dependencies
npm install

# start dev server (http://localhost:4321)
npm run dev

# build for production
npm run build

# preview production build locally
npm run preview
```

## Formatting

```bash
npx prettier --write .
```
