# Backend logos

SVGs sourced from [LobeHub Icons](https://github.com/lobehub/lobe-icons), under the included MIT license. Brand marks belong to their respective owners.

Source directory: https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons

- `anthropic.svg`, `openai.svg`, `cursor.svg`, `opencode.svg`, `google.svg`: monochrome originals with the fill set to warm white for the dark background.
- `google.svg` represents the Google Antigravity backend.

All files use explicit 24 × 24 dimensions instead of font-relative dimensions. Downloaded 2026-09-17; served locally without a runtime dependency.
